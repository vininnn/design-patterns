# design-patterns
Implementação de diferentes padrões de projeto/design patterns para disciplina de Engenharia de Software.

O repositório contém implementações de padrões clássicos de projeto, incluindo os padrões catalogados pelo GoF (Gang of Four), além de variações e abordagens amplamente utilizadas na prática, como a Simple Factory.

As descrições conceituais e implementações dos padrões foram baseadas no conteúdo do website [Refactoring Guru](https://refactoring.guru/).

Durante o desenvolvimento, foi utilizada uma LLM (ChatGPT) para apoio na revisão de conceitos e validação de implementações.
